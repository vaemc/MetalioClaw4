# 副屏（USB 扩展显示）

将 Metalio Claw4 作为电脑的 **USB 扩展屏**（参考乐鑫 `usb_extend_screen` + xfz1986 IDD 驱动）：JPEG 帧刷屏、触摸回传 HID，并可选通过 USB 音频（UAC）从电脑扬声器播放声音。

本目录提供 Windows 侧驱动安装包；设备端入口为主屏 App **「副屏」**。

| 项目 | 说明 |
|:---|:---|
| 分辨率 | **720×720** |
| USB VID / PID | `0x303A` / `0x2986`（Espressif Vendor） |
| 驱动安装包 | [`xfz1986_usb_graphic_250224_rc_sign.exe`](./xfz1986_usb_graphic_250224_rc_sign.exe) |
| 固件实现 | `main/usb_extend_screen/`、`main/display/screen/secondary_screen/` |

---

## 1. 安装 Windows 驱动

1. 在本仓库下载并运行：
   - `secondary_screen/xfz1986_usb_graphic_250224_rc_sign.exe`
2. 按安装向导完成（需管理员权限时按提示允许）。
3. 安装完成后**先不要急着拔线**；确认驱动安装成功即可。

> 驱动来源与协议说明见 [xfz1986/esp32_usb_graphic](https://github.com/xfz1986) 相关仓库；此处仅随本项目分发已签名安装包，便于设备侧文档与 UI 指向同一路径。

---

## 2. 开启副屏（显示）

1. 用 **USB 数据线**（需能传数据，非仅充电线）连接电脑与设备。
2. 在设备主屏打开 **「副屏」** App。
3. 点击底部 **「开启副屏」**（设置 Tab 可调 JPEG 画质 / 最大帧率 / 单帧上限，下次开启生效）。
4. 电脑上打开 **设置 → 系统 → 显示**：
   - 应能看到第二块显示器；
   - 显示模式选择 **「扩展」**（不要用「复制」若你希望当独立副屏）。
5. 分辨率保持 **720×720**（或由驱动/系统自动协商）。
6. **触摸**：扩展屏区域内点击/滑动会经 HID 回报到电脑（等同触摸屏）。

### 退出

- 设备上 **短按电源键**，或回到副屏页点 **「关闭副屏」**。
- 离开副屏页也会停止扩展。

### 与虚拟 U 盘互斥

副屏占用 USB Device 枚举（Vendor + HID + 可选 UAC）。若已在「SD 卡」里 **启用虚拟 U 盘**，请先停用再开副屏，避免 USB 角色冲突。

---

## 3. 声音播放（USB 扬声器）

副屏开启后，设备会以 **USB 音频设备（仅扬声器，无麦克风）** 枚举到电脑。电脑播放的声音可从 Claw4 本机喇叭输出。

### Windows 操作

1. 确认副屏已成功开启且设备管理器中能看到对应 USB 音频设备（名称通常含 **Espressif / Vendor / speaker** 一类字样，以系统显示为准）。
2. 右键任务栏音量图标 → **打开声音设置**（或「声音」控制面板）。
3. **输出设备** 选择本设备对应的扬声器（不要选电脑自带音箱，除非你只想听电脑）。
4. 在任意播放器（浏览器、音乐软件等）播放音频，声音应从 **设备扬声器** 播出。
5. 音量可用 Windows 系统音量，或播放器音量调节。

### 说明与限制

- 当前固件为 **仅 Speaker（UAC MIC 关闭）**，减轻 Full-Speed USB 端点压力；**不能**把设备麦当 USB 麦克风用。
- 开启副屏时会暂停设备侧原有语音会话 / I2S 占用，避免与 UAC 抢音频通路；退出副屏后恢复。
- 若设备管理器里音频设备闪断或枚举失败：换数据线 / USB 口，或暂时关闭其它占用同一 USB 的功能后重试。

## 4. 常见问题

| 现象 | 建议 |
|:---|:---|
| 电脑无第二屏 | 是否已装驱动；是否点了「开启副屏」；线是否支持数据；显示模式是否为「扩展」 |
| 颜色发偏 / 残影 | 固件侧已按 RGB888 + 面板时序配置；升级到最新固件后重试 |
| 触摸点在电脑侧偏移 | 确认系统显示缩放与扩展屏分辨率均为 720×720 |
| 无声音 | 输出设备是否选中本机 USB 扬声器；副屏是否仍在运行 |
| 开启失败 | 检查 USB 线；确认未同时启用虚拟 U 盘 |
